# 从一件事开始

## 快速翻页

有一句具体困惑就直接写短页。不为了“三个细节”补造背景；可以写“这句话里暂时能看见的，是……”。没有问题只问“今天最绕不过去的是什么？”。保留异议、判据和可选实验。用户说没对上，问哪一处不贴近，再换角度，不靠连续抽签追求“准”。

## 一起读：按信息收益推进，通常 3–5 轮

先读 reasoning.md。以下是可选问题，不是固定问卷。已知就略过；每次发问前说明已经看见的一个具体区别。用户目标是解决实际问题时先帮他推进现实步骤，书页随后提供角度。

| 此刻缺什么 | 可以问 |
|---|---|
| 具体场景 | 最近一次卡住是什么时候？当时发生了哪件小事？ |
| 想要的变化 | 如果下个月这件事好一点，你希望哪个具体变化先发生？ |
| 尝试与代价 | 你试过哪一步？停在什么地方？ |
| 解释分歧 | 你更像缺少样本，还是已经有样本、只是承受不了代价？也可能都不是。 |
| 校准命名 | 我更想把这一页叫……，你会怎么改这句话？ |

素材足够或用户要求直接交付时出页。不要在出 HTML 前重复问“这句戳到你了吗”形成额外审批。用户已让你直接出页时，把判断写成暂定理解即可。

示范：用户说“29 岁做会计六年，插画学两年，接过三单，父母说稳定最重要”。回应“你已经接过三单，所以我们有真实样本。那三单里，有没有一位客户回来找你做第二次？”一轮只问一个问题，不同时问存款、作品集、梦想与父母关系。

## 专题卷宗

适用于用户明确想认真梳理一个转折点；不自动把一次纠结扩大为人生规划。先确认本次想覆盖的 2–3 个问题，每轮问一个，允许跳过。不强制 20 题。

素材足够时形成“你的答案之书·这一章”，2–3 页可在同一 HTML 导航。每页独立命名、原话、坐标、异议、判据与实验。末尾在对话中邀请用户选一个最轻的实验；不同时布置三件必须完成的事。

JSON 外层格式：`{"chapter_title":"转弯之前","pages":[{完整页面},{完整页面}]}`。`render` 自动给每页锚点与目录；不要求另建模板。

## 难以继续时

用户说“不想说”“算了”，允许停下。拒绝一个问题不说明回避。没有合适书页可以提供不挂名的理解与一个观察方向，诚实写出材料不足。用户明确只想看解释，不强迫行动或保存。
