# 八主题路由

先看用户这次需要判断什么，再选书。下表是候选入口，不能从触发词直接推断心理根源。ID 只是阅读起点，不要求每个案例固定命中一本书。

| 主题 | 可能的原话 | 主页候选 | 另一方向 |
|---|---|---|---|
| 选择与后悔 | 该不该走、后悔、转行 | daodejing-44-1；mozi-feigong-zhong-1 | lunyu-2-12：先看能力能否携带 |
| 恐惧与焦虑 | 不敢、一直担心、想得停不下来 | apology-29a；hamlet-3-1-83 | daodejing-64：把未知缩成一个可做的步骤 |
| 关系与冲突 | 吵架、摊牌、被误解、不合群 | lunyu-15-23；zhuangzi-shanmu-1 | mozi-jianai-zhong-2：换位也有现实边界 |
| 金钱与安全 | 钱不够、亏损、不敢花 | daodejing-44-2；mozi-feigong-zhong-1 | lunyu-4-09：收入并非所有价值；不据此建议交易 |
| 意义与虚无 | 空、没意思、图什么 | apology-38a；daodejing-48 | zhuangzi-renjianshi-3：不把所有生活换成效用 |
| 自我与身份 | 只是工具、配不上、总在比较 | lunyu-2-12；daodejing-33-1 | zhuangzi-renjianshi-3：不把自我证明变成全天任务 |
| 时间与消耗 | 忙、学不完、消息不停 | zhuangzi-yangshengzhu-1；lunyu-9-17 | daodejing-64：选择之后仍要留下小步行动 |
| 失败与脆弱 | 搞砸了、被裁、不敢再试 | lunyu-15-29；daodejing-64 | daodejing-76：避免把坚硬当唯一生存方式 |

异议候选可以跨主题，但必须针对同一处境。主题是宽分类；记录中的 `issue_key` 要更窄，如 `career-portable-skill`、`partner-response-agreement`。同属关系主题，不等于同一问题。

## 现代层：25 本的使用范围

以下仅作为找书方向，不是已核验引文库。需要展开某一书意时先核对可信材料；不能仅凭这张表把模型判断归给作者。

| 书 | 可借的视角 | 限制 |
|---|---|---|
| 思考，快与慢 | 直觉、判断偏差 | 不用偏差标签否定用户全部判断 |
| 穷查理宝典 | 多角度与反向检查 | 不冒充某一投资结论 |
| 认知觉醒 | 觉察与行动 | 不将一切归因于自律 |
| 反脆弱 | 暴露、试错与损失上限 | 不是伤害越多越好 |
| 黑天鹅 | 不确定性与事后解释 | 不是停止规划 |
| 富爸爸穷爸爸 | 现金流和资产的通俗讨论 | 不把通俗分类当会计、税务定义 |
| 纳瓦尔宝典 | 专长、杠杆、可复制产出 | 不保证财富或鼓动离职 |
| 金钱心理学 | 风险感受与金钱行为 | 不决定买卖和仓位 |
| 高效能人士的七个习惯 | 优先次序与可影响范围 | 现实资源不足不等于态度差 |
| 原则 | 记录判断与复盘 | 作者的经历不是通用最优解 |
| 非暴力沟通 | 观察、感受、需要、请求 | 不要求当事人与施害者沟通来换安全 |
| 卓有成效的管理者 | 时间记录、贡献、取舍 | 不扩大成个人价值评判 |
| 被讨厌的勇气 | 人际边界与课题 | 不把所有困难说成自主选择 |
| 当下的力量 | 留意当下体验 | 不取代治疗或现实问题解决 |
| 活出生命的意义 | 回应处境与个人意义 | 不比较痛苦，不编集中营细节 |
| 心流 | 活动中的投入与反馈 | 不把投入变成生产力义务 |
| 情绪急救 | 应对日常挫折的线索 | 不诊断或开处方 |
| 人类简史 | 共享叙事的宏观视角 | 不替代个体情境证据 |
| 乌合之众 | 历史上的群体心理观点 | 有时代局限，不给群体贴低智标签 |
| 终身成长 | 能力可发展、反馈可用 | 不等于只夸努力或否认资源差异 |
| 指数基金投资指南 | 金融知识入口 | 仅工具层；不用于具体交易指令 |
| OKR 工作法 | 把目标转为可观察结果 | 仅工具层；无需给生活处处设指标 |
| 小狗钱钱 | 低门槛的金钱行为练习 | 寓言层；不承担投资风险判断 |
| 置身事内 | 理解制度与宏观背景 | 仅背景层；不直接裁定个人抉择 |
| 枪炮、病菌与钢铁 | 历史条件与结构因素 | 仅背景层；不拿宏观论点决定个人能力 |
