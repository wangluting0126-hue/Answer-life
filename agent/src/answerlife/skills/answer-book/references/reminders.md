# 把一周之后留给真实结果

用户主动说“提醒我复盘”“一周后再看”时，确认实际日期、当地时间与时区；不默认午夜，不自动创建云端日程。本功能生成 ICS，用户导入日历后由日历负责通知。它不能定时运行 AI，也不保证通知权限已开启。

```bash
python3 scripts/answer_book.py remind \
  --data examples/job-search.json \
  --on 2026-11-12 --at 20:30 --timezone Asia/Shanghai \
  --out output/七天后回看.ics
```

示例日期固定用于演示，真实用户用其确认的日期。Python 使用 IANA 时区转成 UTC，ICS 含事件与当天 VALARM；日期、时间、时区无效时拒绝，夏令时跳过的不存在时刻也拒绝。重复生成同一实验与同一时刻会给相同 UID，但是否更新还是重复事件由日历客户端处理。

事件标题只写“回到答案之书，看看那件小事”，正文包含实验内容，不放整段原话和私人文件路径。CLASS:PRIVATE 是日历属性，不是加密；导入云日历意味着该日历会保存事件正文，用户可以自行删减。文件默认不覆盖。

提醒出现后，用户回到对话带来结果；AI 才运行 update/review 并调整解释。日历没有自动写权限，点击阅读页彩蛋也不改变 session 状态。没有宿主调度器时，不说“到时我会来找你”。

## 书签彩蛋

HTML 底部有“夹一枚书签”。用户点开才出现一句本产品创作的短句，并提示下次可以带着“我试过了，结果是……”回来。没有隐藏请求、远程请求、追踪、日期封锁或冒充古人原话；无 JS 时仍能原生展开。克制地提供一个回来的入口。
