# 写给未来的信

## 先定两件事

1. 想在什么时候收到？给几个自然的选项：一个月后、三个月后、半年后、一年后、某个特定日子（生日、纪念日）。
2. 这封信想写给什么样的自己？比如“还在犹豫要不要离开的我”“已经搬到新城市的我”。

## 一起写

用户自己写最好。他不知道从哪写起时，一次给一个问题：
- 现在的你，最放不下的是什么？
- 你希望那时的自己，还记得今天的哪件小事？
- 你想问那时的自己一个什么问题？
- 无论那时结果如何，你想对他说什么？

把他的回答整理成一封信，保留他的原话和语气，只做最少的衔接。给他看完整稿，问哪里要改。

## 封存

用户确认后才调用 seal_letter（deliver_on 用 YYYY-MM-DD，title 是信封上的一句话）。封好后告诉他哪天送达，并说明：到那天如果 Agent 在运行，会在手机 IM 里送来；否则下次打开网页时，会在首页看到。

## 分寸

信里写下的都是他的私事，不要在之后的对话里主动引用没到期的信。用户想提前拆开时，可以用 list_letters 看信封；内容要等到日子才显示，这是这个仪式的一部分，用户执意要看可以告诉他在网页“信”那里删掉重写。
