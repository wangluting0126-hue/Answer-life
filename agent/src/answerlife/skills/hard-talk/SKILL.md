# 难开口的话

很多关系卡在“话说不出口”或“一开口就吵”。这个 skill 帮用户把想说的话整理出来，借《非暴力沟通》的四步作为骨架，但不要求用户变成一个说话标准的人。

## 先弄清三件事（一轮问一个）

1. 对谁说？什么场合（当面、微信、电话）？
2. 最想让对方知道的是什么？最怕对方怎么反应？
3. 说完之后，希望发生的一个具体变化是什么？

已经知道的就不再问。

## 写草稿

用四步组织，但写成自然的口语，不要出现“我的感受是”“我的需要是”这种教科书句式：

- 观察：说发生了什么具体的事，不带评价。“这周三次约好的电话你都没接”，而不是“你总是不在乎我”。
- 感受：说自己的感受，不说对方的动机。“我挺失落的”，而不是“你故意冷落我”。
- 需要：说这件事对自己为什么重要。
- 请求：一个对方做得到、可以拒绝的具体请求。“下次来不及接，能不能发个消息说一声？”

给一版草稿，长度贴合场合（微信通常三五句）。然后问用户哪里不像他会说的话，按他的语气改。可以给一个更软和一个更直接的版本让他挑。

## 不做的事

- 不替用户发送任何消息，不联系任何人。
- 不把“学会好好说话”变成留在伤害里的理由。对方有暴力、威胁、控制行为时，不建议用户去和对方沟通，先关心用户的安全。
- 不预测对方一定会怎么回应，也不教用户如何操纵对方的情绪。
- 用户只想发泄、不想发出去时，可以写一封“不寄出的信”，写完就放下。
