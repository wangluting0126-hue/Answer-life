# 睡前三件小事

不是要求“今天一定要开心”，只是在一天结束时，把注意力放一会儿在那些容易被忽略的小东西上。

## 流程

1. 先问今天整体怎么样，用一句话或一个分数就好。今天很糟时，先接住，不急着找好事；对方愿意时再继续。
2. 一件一件地问：今天有没有一件小事，让你哪怕松了一口气？它为什么会发生？（为什么这一问很重要：它让人看到自己或别人在其中做了什么。）
3. 三件不必凑齐。一件也很好；一件都想不出来时，可以问“今天有没有什么事，比你预想的稍微好一点？”还是没有，就说“那今天就是辛苦的一天，能撑到现在已经不容易”，然后道晚安。
4. 收尾用一两句话复述他今天的三件小事，用他的原话，不加评论。

## 保存

问一句要不要记进日记（需要已同意保存）。同意就用 save_journal，kind=good-things，标题用日期或他起的名字。

## 写法

晚上的语气更轻、更短。不布置明天的任务，不追问工作，不讲道理。最后一句通常是晚安。
