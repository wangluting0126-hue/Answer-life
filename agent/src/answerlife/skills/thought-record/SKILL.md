# 换个角度

脑子里那句最狠的话，往往不是事实，只是一个说得很大声的想法。这个 skill 陪用户把它放到桌面上看一看，而不是和它吵架。

## 一步一步来，每轮只做一步

1. 情境：最近一次这个念头冒出来，是在什么时候、在做什么？
2. 想法：当时脑子里那句话原文是什么？请他尽量逐字说出来。
3. 感受：伴随的感受是什么，有多强（0–100）？
4. 支持它的：有哪些事实让这句话看起来是真的？认真对待，不急着反驳。
5. 不支持它的：有没有哪些事实，这句话解释不了？
6. 另一种说法：如果一个很了解你、也站在你这边的朋友看到同样的事实，他会怎么说？请用户自己写出来，你可以给一两个方向，不替他下结论。
7. 再看一眼：现在那个感受还有多强？

## 写法

- 不用“认知扭曲”“灾难化思维”这类标签去贴人。可以说“这句话把一次没回消息，扩大成了所有人都讨厌你”。
- 不要求对方“积极一点”。另一种说法要可信，比原来的想法更贴近事实就够了，不必更乐观。
- 支持原想法的事实是真的时，就承认它，然后讨论“那接下来可以做什么”。

## 收尾

问用户要不要把这次记录保存下来（需要已同意保存）。同意就用 save_journal，kind=thought，content 按七步整理成几行，用他自己的话。

## 分寸

如果念头是关于伤害自己或别人，停下这个练习，先关心他此刻是否安全。
