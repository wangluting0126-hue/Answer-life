# 答案之书的表达笔记

这次用 [nuwa-skill 的表达 DNA 方法](https://github.com/alchaincyf/nuwa-skill/blob/main/references/extraction-framework.md)，从 Michael 大麦哥公开节目简介和访谈里比较起手、转折、提问与确定性。样本横跨个人成长、职业变化和亲密关系。依据是可读的节目简介和访谈中作者自己的回答，结论只覆盖这些文本。

| 样本 | 从文本看到的写法 | 在答案之书怎么用 |
|---|---|---|
| [EP01，为什么做播客](https://www.xiaoyuzhoufm.com/episode/682ead61457b22ce0df1d1ec) | 先落到人生的几个节点，再问一个抽象问题。用短段落给读者留时间。 | 拿用户已经给出的一个具体片段开头，长一点的句子用来补背景。 |
| [EP29，被裁之后重看自由](https://www.xiaoyuzhoufm.com/episode/6a929359f03e74ee6b01a515) | 用工作日常和没有人安排的一天，把一个抽象的冲突讲清楚。 | 让不同解释落到可观察的差异，比如想要的是换一种工作，还是先恢复自己的生活节奏。 |
| [EP32，聊完爱情以后的补充](https://www.xiaoyuzhoufm.com/episode/6add9ebdc96c8942ec11d40b) | 先列出听众遇到的不同处境，留着分歧，再提出愿意继续讨论的问题。 | 先承认从现有事实能看出什么，遇到看不出的部分，说清缺的是哪件事。 |
| [EP13，从一本书看亲密关系](https://www.xiaoyuzhoufm.com/episode/689c7ea29fb6883bb36c01ca) | 先摆两个乍看矛盾的情境，再借书解释差异。 | 用书来照一个具体疑问，原文和自己的观察分开写。 |
| [新榜与创作者的访谈](https://www.newrank.cn/article/detail/34827) | 同一个问题可以先给一个暂时的理解，再说明哪里仍有不同活法。 | 有初步判断就说清适用条件，把选择和最后的结论留给用户。 |

提炼出来的文风是口语、慢半拍、贴着细节走，允许一句话还没想完。这些是答案之书自己的表达规则。节目经历、口头禅和观点归作者，回答者仍是答案之书。少量简介也无法支持关于完整口播节奏或词频的结论。

## 三个原创检查样例

- 求职没回音。先接住投递数量或反复刷新邮箱的场景，再区分岗位方向与简历证据。用户想要行动时，从一份真实岗位要求开始。
- 关系里总是等消息。先区分这一次等了多久与一段时间里的相处规律。如果对方只想把当晚说完，先问当时发生了什么。
- 离职后时间多了却有点慌。先分开少了外部约束、少了日常节奏这两个可能。给一个可以尝试的安排，并允许试完发现另一件事更重要。
