# 阅读页视觉规范

参考：[Life Designer 公开示例](https://jackychen-12.github.io/life-designer/) 与 [源码](https://github.com/Jackychen-12/life-designer/blob/main/docs/index.html)，查看日期 2026-11-05。借鉴其纸面阅读、窄栏、字体层级与克制配色；本包模板独立编写，未复制其长报告与时间胶囊流程。

| 元素 | 本包约定 |
|---|---|
| 底色 | 暖白 #FAFAF8；注记纸色 #F0EDE6 |
| 文字 | 墨黑 #1A1A1A；次级 #65655F；细线 #D8D4CC |
| 强调 | 深蓝 #2B4C7E，仅用于原文线、实验标记与交互 |
| 标题/引文 | 系统宋体；中文正文优先宋体，功能文字系统黑体 |
| 编号/日期 | 系统等宽字体；小号但保持可读对比 |
| 版心 | 最大 720px，桌面左右内边 40px；移动端 22px |
| 节奏 | 正文 17–18px，行高 1.95；段落间距 18px；主要节间 42–56px |
| 装饰 | 一条细线、书页号、极少深蓝；不做悬浮卡片墙 |

版式顺序：书名与日期 → 居中的本页标题 → 用户原话 → 文本坐标与白话 → 原文 details → 异议 → 判据与七天实验 → 反问 → 出处脚注与导出。

正文不使用项目符号和粗体。必要标签低调但可读。短引默认展开、长引默认收起，点击能查看并打开来源链接。卷宗目录是页间导航，不混入正文。

所有内容在初始 HTML 中可读；JavaScript 仅增强复制、下载和打印。不依赖 CDN、在线字体、远程图片、模型接口或浏览器存储。移动端不截断长句，使用键盘能操作所有按钮和折叠块，显示焦点。减少动画偏好下没有过渡动画。

打印为白底，隐藏工具栏，展开原文；不用暗示长篇内容一定能塞进一张 A4。“一页”指一个完整阅读单元。Markdown 始终作为同名文件一并交付，浏览器下载只是方便入口。
